S1 — Product Moment

Cùng 1 task, 2 paradigm khác nhau. Ngành: Lập trình (AI coding).

Nhiệm vụ chung

Refactor function Python process_user_order (~55 dòng) → 3 function nhỏ hơn + 1 pytest unit test/function.

Sản phẩm A — Google Antigravity

  • Agent-first IDE, fork VS Code (Google, ra 18/11/2025)
  • FREE public preview (Gmail) — Google AI Pro $19.99/tháng
  • Multi-model: Gemini 3.1 Pro, Gemini 3 Flash, Claude Opus 4.6, Claude Sonnet 4.6, GPT-OSS 120B
  • Entry: tải IDE → mở project → "Mission Control" (Manager View) dispatch agent

Sản phẩm B — GitHub Copilot

  • Extension trong VS Code, Microsoft/GitHub (2021)
  • Pro $10/tháng (free cho student); Pro+ $39 cho Claude Opus / GPT-5
  • Default GPT-4o; Pro+ unlock Claude Opus 4.6, Gemini 2.5 Pro
  • Entry: cài extension → ghost text autocomplete + Chat (Cmd+I) + Agent Mode

S2 — Workflow Evidence

Trước / Trong / Sau khi prompt — agent dispatch vs inline chat.

BướcAntigravityCopilot
TrướcMở Mission Control, mô tả task, chọn model (Gemini 3.1 Pro / Claude Opus 4.6)Mở Copilot Chat (Cmd+I), chọn context = file đang mở
TrongAgent plan task list → tạo artifacts (code + test) → ghi log từng bước thực hiện, có thể tự open browser verifyTrả từng function trong chat, user "Insert into Editor"
SauManager View hiển thị diff per-file + screenshot test pass → 1-click applyPhải tạo file test_orders.py thủ công, paste code, chạy pytest tay

3 friction areas đo được

  • Autonomy: Antigravity agent tự verify (chạy test, screenshot) — Copilot dừng ở "Insert code", verify là việc của user
  • Multi-agent: Antigravity dispatch tới 5 agent song song trong Mission Control — Copilot 1 chat tại 1 thời điểm
  • Codebase awareness: Antigravity index toàn project + có thể duyệt browser — Copilot chỉ thấy file đang mở (trừ Enterprise)

S3 — Output & Trust

Chất lượng code + 6 dấu hiệu đáng tin.

Tiêu chíAntigravityCopilot

Type hints đầy đủ✓✓ (Gemini 3 mặc định strict)Một phần (thiếu return type khi GPT-4o)
Docstring đúng PEP 257✓✓
Pytest coverage edge cases4 case/function (agent tự verify)2 case/function

6 Trust signals

  • Artifact trail: Antigravity ghi task list + screenshot + log → audit được — Copilot chỉ có Chat history
  • Auto-verify: Antigravity tự chạy test trước khi báo done — Copilot dừng ở generate code
  • Diff preview: cả 2 đều có, Antigravity per-file rõ hơn
  • Model transparency: Antigravity hiển thị model đang dùng — Copilot mặc định ẩn
  • Citation training data: cả 2 không công khai
  • Risk: Copilot có vụ kiện copyleft (Doe vs GitHub 2022); Antigravity dữ liệu hoạt động gửi về Google → privacy concerns trong Enterprise

S5.5 — Data Flywheel + Feedback Loop

Antigravity

  • User feed lại: agent task accept/reject, artifact rating, browser action recording
  • Compounding: feed lại Gemini 3 base model (Google sở hữu) — vòng compounding mạnh hơn Cursor (mượn API)
  • Browser data: Antigravity ghi lại browser interaction → trove data unique (no competitor có)
  • Feedback systematic: ✓ tích hợp Google AI infrastructure
  • Big tech tấn công?: bản thân là Google — Antigravity là disruptor, không phải nạn nhân

GitHub Copilot

  • User feed lại: accept/reject suggestion, thumbs chat
  • Compounding: scale data lớn (1B+ repos public) nhưng loop tách rời — feedback vào Azure ML, không vào user UX trực tiếp
  • Feedback systematic: chậm — model mới qua IDE update
  • Big tech tấn công?: bản thân là big tech

Kết luận: Antigravity flywheel mạnh hơn vì (a) tự sở hữu Gemini 3, (b) browser interaction data unique. Copilot scale lớn hơn nhưng loop chậm.

S5.7 — Spark → Loop → System

Antigravity

  • Spark ✓ Mission Control "AI tự verify task" — spark moment cho ai chưa thấy agent IDE
  • Loop ✓ (đang xây) — daily-driver bị rate limit drama cản; user trở về Cursor/Copilot
  • System ✗ chưa — chỉ ~6 tháng tuổi, chưa có Enterprise tier, chưa có team workflow
  • 12 tháng: Google sẽ ép Antigravity vào Google AI Pro bundle, target 5-10M user; rate limit issue phải fix; có thể GA cuối 2026

GitHub Copilot

  • Spark ✓ Ghost text autocomplete (2021) — spark đầu của ngành
  • Loop ✓ Autocomplete + Chat + PR review trong workflow GitHub
  • System ✓ Agent Mode + Copilot Workspace + Pages → "OS for dev"
  • 12 tháng: đẩy mạnh Azure DevOps + Enterprise; phản công Antigravity bằng Pro+ Claude Opus + Workspace

Kết luận: Antigravity ở Spark đầu, Loop chưa ổn; Copilot đã tới System. Antigravity có thể "leap" nếu Google fix rate limit + ra Enterprise tier.

S5.8 — Liên hệ Lab 1 (Chegg)

Antigravity / Copilot có rủi ro "Chegg moment" không?

Bài học Lab 1: Chegg sụp 99% trong 4 năm vì (i) niche quá rộng, (ii) moat "rented land" trên Google, (iii) phản ứng chậm 5 tháng.

Áp dụng vào Antigravity

  • Niche: hẹp hơn Chegg (agent power user) — rủi ro thấp hơn
  • Moat "rented land": KHÔNG — Google sở hữu Gemini + Workspace + Cloud → moat tự sở hữu hoàn toàn
  • Verdict rủi ro disruption: Thấp — Antigravity là disruptor (giống ChatGPT vs Chegg), không phải nạn nhân
  • Rủi ro riêng: execution — Google nổi tiếng "kill products" (Google+, Stadia); nếu rate limit drama tiếp diễn 6 tháng, Google có thể bỏ Antigravity giống Stadia

Áp dụng vào Copilot

  • Niche rộng (giống Chegg) nhưng moat tự sở hữu (Microsoft owns GitHub + VS Code + Azure)
  • Rủi ro disruption thấp — bản thân là big tech
  • Rủi ro khác: Antigravity + Claude Code CLI ăn từ phân khúc cao xuống (giống ChatGPT ăn Chegg); nếu Copilot không leap sang full agent → có thể trở thành "homework help" của AI IDE

Bài học chính từ Lab 1 áp dụng đây: cuộc đua AI IDE đang ở giai đoạn PMF Treadmill — kỳ vọng "agent tự verify" có thể nhảy bậc trong 6-12 tháng; Copilot phản ứng chậm = mất share giống Chegg.
