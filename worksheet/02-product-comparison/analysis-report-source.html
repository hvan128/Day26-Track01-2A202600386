S1 — Product Moment

Cùng 1 task, 2 trợ thủ AI. Ngành: Lập trình (AI coding assistant).

Nhiệm vụ chung

Refactor function Python process_user_order (~50 dòng) → 3 function nhỏ hơn + 1 pytest unit test/function.

Sản phẩm A — Cursor

  • IDE fork của VS Code, Anysphere
  • Pro $20/tháng
  • Entry: tải IDE → mở project → Cmd+L (chat) / Cmd+K (inline edit) / Composer
[ẢNH: product-A-1-entry.png — Cursor IDE màn hình đầu]

Sản phẩm B — GitHub Copilot

  • Extension trong VS Code, Microsoft/GitHub
  • Pro $10/tháng (free cho student)
  • Entry: cài extension → ghost text autocomplete + Chat panel (Cmd+I)

6 Trust signals

  • Cite context: Cursor cite file gốc — Copilot không cite

S5.5 — Data Flywheel + Feedback Loop

Cursor

  • User feed lại: Cmd+K accept/reject, Composer apply/reject, Tab accept rate, chat thumbs
  • Compounding: Cursor 2.0 train proprietary Composer model trên dữ liệu accept/reject từ ~1M DAU → chuyển từ "rented" sang "own model"
  • Systematic feedback: ✓ (Tab accept rate là metric chính)
  • Big tech tấn công: Microsoft clone Composer trong Copilot Pro+; OpenAI Codex cạnh tranh trực tiếp

GitHub Copilot

  • User feed lại: accept/reject suggestion, thumbs up/down chat
  • Compounding: scale data lớn nhất (1B+ repos public) nhưng loop tách rời — feedback vào Azure ML, không vào user UX trực tiếp
  • Systematic feedback: Có nhưng chậm — release model mới qua IDE update
  • Big tech tấn công?: Bản thân là big tech — đối tượng tấn công Cursor

Kết luận: Cursor xây flywheel nhanh hơn (proprietary model 2025-2026); Copilot có data scale lớn hơn nhưng loop chậm hơn.

S5.7 — Spark → Loop → System

Cursor

  • Spark ✓ Cmd+K "edit by description" (2022-2023)
  • Loop ✓ Composer + Chat + Tab + Apply diff hằng ngày
  • System ✓ (đang xây) Cursor 2.0 multi-agent + proprietary Composer model + Background agents
  • 12 tháng: chuyển sang full agent system, giảm phụ thuộc API; có thể IPO 2026-2027 sau Series E $50B

GitHub Copilot

  • Spark ✓ Ghost text autocomplete (2021) — spark đầu tiên của ngành
  • Loop ✓ Autocomplete + Chat + PR review trong workflow GitHub
  • System ✓ Agent Mode + Copilot Workspace + Copilot Pages → "OS for dev"
  • 12 tháng: đẩy mạnh trong Azure DevOps + ép vào Enterprise; tăng paid sub lên 8-10M

Kết luận: Cả 2 đều ở giai đoạn System — Cursor xây từ feature signature, Copilot xây từ platform integration.

S5.8 — Liên hệ Lab 1 (Chegg)

Cursor / Copilot có rủi ro "Chegg moment" không?

Bài học Lab 1: Chegg sụp 99% trong 4 năm vì (i) niche quá rộng, (ii) moat "rented land" trên Google, (iii) phản ứng chậm 5 tháng.

Áp dụng vào Cursor

  • Niche: hẹp hơn Chegg (power user dev) — rủi ro thấp hơn
  • Moat "rented land": CÓ — fork VS Code (Microsoft kiểm soát), dùng OpenAI/Anthropic API
  • Phản ứng: Cursor 2.0 train proprietary Composer → đang escape rented land trước khi big tech khoá
  • Verdict rủi ro: Trung bình — Microsoft / OpenAI có thể ép, nhưng Cursor chủ động xây own model

Áp dụng vào Copilot

  • Niche rộng (giống Chegg) nhưng moat tự sở hữu (MSFT owns GitHub + VS Code + Azure)
  • Verdict rủi ro: Thấp — bản thân là big tech, không phải nạn nhân
  • Rủi ro khác: Cursor + Claude Code + OpenAI Codex CLI ăn từ phân khúc cao xuống (giống ChatGPT ăn Chegg)
